# Fixed-scope Backend API Integration Sprint

**Audience:** Shopify agencies, small SaaS teams, POS/CRM integrators, and online retailers that need extra backend integration capacity.

## What I can help with

- Integrate a documented REST API with one destination system.
- Map and validate orders, products, inventory, or CRM records.
- Handle common operational failures: retries, timeouts, duplicate events, and structured error logs.
- Provide a short test report and handover notes.

## Example offer (for market testing)

**API / Automation Starter — RM700–1,200** for one clearly scoped task, subject to reviewing technical access and complexity. This is a price hypothesis, not a fixed quote for any unspecified API.

The quote should always identify: (1) source and destination, (2) affected data fields, (3) access/security model, (4) run frequency/trigger, (5) error handling, (6) tests and acceptance criteria, (7) delivery date and revision limit.

**Not included by default:** 24/7 on-call support; unlimited revisions; hosting fees; production payment processing; legacy system discovery; undocumented API reverse engineering; compliance or security certification.

## Working arrangements

- Remote and fixed-scope; development primarily on weekends.
- Limited asynchronous weekday coordination, subject to availability.
- Written milestone and payment terms before starting.
- Use client-provided sandbox credentials; never request passwords in plain text.
